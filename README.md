# BDU Student Portal - Android App

A mobile Android application for Bahir Dar University students to check their academic results, GPA, and department placement.

## Features

- Secure Login with BDU credentials
- Academic Results (SGPA, CGPA, grades)
- Department Placement status
- Student Profile
- Mobile-first design
