# Security Policy

## What BD Buddy does with your credentials

When you log in:

1. You type your BDU username and password into the login form.
2. The browser sends them to BD Buddy's server (`server.js` on Render).
3. The server forwards them to `studentportal.bdu.edu.et` over the network.
4. BDU verifies the credentials and returns your academic data.
5. The server passes the data back to your browser.
6. The password is **discarded from memory** and never written to disk, logged, or committed.

**Important:** BD Buddy is a proxy, not a direct connection. Your credentials
transit BD Buddy's server in memory. They are never stored, but they do pass
through our infrastructure. If this is not acceptable, use the official BDU
portal directly.

## Credentials policy for contributors

**Never commit credentials to this repository.**

- No usernames in code, tests, or documentation
- No passwords in `.env` files that are committed
- No demo accounts that are actually real accounts
- No screenshots that show login credentials

If you find credentials in the repo (including git history), please open an issue immediately.

## Secrets

- HMAC secret used for document verification is stored as `HMAC_SECRET` env var
- Never commit `.env` files
- Never include secrets in patches or pull requests
- Rotate secrets if they leak

## Document verification

BD Buddy's verification system uses **HMAC-SHA256 signatures** to prove a
document was issued by our server.

**What it proves:**
- The serial was generated by BD Buddy's server
- The serial has not been tampered with since it was issued

**What it does NOT prove:**
- That the PDF content itself wasn't altered (only the serial is signed)
- That the underlying academic data is accurate (that's BDU's domain)
- That the document is an official BDU record

For official confirmation of your BDU record, always check with the official
portal or the BDU registrar.

## Reporting a security issue

If you find a vulnerability:

1. **Do not** open a public issue for sensitive reports
2. Contact the maintainer via the contact page at `/pages/contact.html`
3. Include:
   - A description of the issue
   - Steps to reproduce
   - Any relevant logs or screenshots (do not include real credentials)

We'll respond as soon as possible.

## Out of scope

The following are **not** security issues for BD Buddy:

- The official BDU portal's own security
- Data accuracy (that's BDU's responsibility — always trust the official portal)
- Missing academic features
- UI/UX issues (open a regular issue)

## Scope

BD Buddy is a student-built project. It is **not** affiliated with Bahir Dar
University. The maintainer provides it as a free, open tool without warranty.
